# Code of Conduct · Code de conduite

ZerkiWatch is a friendly, open project. Everyone taking part — in issues, pull requests, discussions — is expected to:

- be respectful and patient, especially with beginners and non-native speakers;
- give and accept constructive feedback;
- keep discussions about the project and its code, with no harassment, insults, discrimination or personal attacks;
- never share other people's private information.

Maintainers may edit, hide or remove contributions that break these rules, and may block people who repeatedly do so. To report a problem, open an issue titled "Conduct" or contact the maintainer through his GitHub profile ([@zerkino](https://github.com/zerkino)).

*FR : soyez respectueux et patients, surtout avec les débutants ; critiquez le code, pas les personnes ; pas de harcèlement ni de discrimination ; ne partagez pas d'informations privées. Les mainteneurs peuvent modérer les contributions qui ne respectent pas ces règles.*
